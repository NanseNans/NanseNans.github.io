Privacy policy

Last updated: 25 October 2026

Bitverse Uploader is a private tool used only by the owner of the Bitverse YouTube channel to upload and schedule the channel's own videos.

What data the tool uses

With the owner's permission, the tool uses the YouTube Data API to upload videos, set their title, description, tags and thumbnail, and schedule when they are published. It reads the channel's name to confirm it is connected to the right channel.

What it does not do

The tool does not collect, store, sell or share personal data about anyone. It does not access other people's accounts, and it does not read viewer data.

Google user data

Bitverse Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: use the support email shown on the app's Google sign-in screen, or contact NanseNans on GitHub.
